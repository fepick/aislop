# 11. 장비 도트 아이콘

사용자가 요청한 장비 선택지 그림을 추가한다. TODO의 장비 구현 항목과 후속 장비 확장을 대상으로 한다.

- ImageGen 기본 모드로 시트 5개를 생성하고, 장비 ID별 32×32 투명 PNG 33개를 `asset/equipment/`에 저장한다.
- 보상 카드에는 아이콘과 기존 레어도·이름·효과를 함께 배치한다. 좁은 세로 화면에서는 아이콘과 정보가 한 줄을 이룬다.
- 모든 장비의 아이콘 경로와 PNG 규격, 저장 복구 후 아이콘 및 선택지 일치, 데스크톱과 모바일 레이아웃, 하위 경로와 운영 배포를 검증한다.

## ImageGen 프롬프트

> Use case: stylized-concept. Asset type: item inventory sprite atlas for an original 16-bit wrestling autobattler. Render EXACTLY the number of listed isolated pixel-art inventory icons on true transparent alpha. Layout is perfectly regular 3 columns by 2 rows (6 icons) or 3 columns by 3 rows (9 icons) equally sized cells, every cell filled by exactly one centered icon. Keep each icon well inside the central 60% of its own cell with very wide clear transparent gutters, especially at exact cell boundaries. Icons should be styled as a native 26 by 26 pixel art painting scaled nearest-neighbor, with visible large square pixels, a distinct near-black stepped outline, 3–4 coherent color ramps, punchy light pixels for dark-background readability, silhouette recognizable when tiny. No drawn grid, no UI, no containers, no tiles, no words, no labels, no numerals, no gradients, no cast shadow, transparent canvas.
