# 08. 경기장과 관중 이벤트

사용자가 추가 요청한 경기장 변형과 관중 이벤트를 TODO의 스테이지 구성 및 최대 3라운드 시리즈에 연결한다.

- 캠페인 스테이지마다 관중석, 링 바닥, 로프와 조명을 다르게 그린다. 실험실은 기존 경기장을 사용한다.
- 크리티컬·로프 드롭킥·일정 피해 이상의 명중에 관중이 반응한다. 의자와 쓰레기 투척은 관중 연출이며 피해나 경직을 가하지 않는다. 경기별 이벤트 시드는 전투와 AI 시드 스트림에서 분리한다.
- 시리즈가 3라운드에 들어가면 시드가 정한 시점과 폭으로 양쪽 로프를 이동한다. 이동 경계, 넉백, 겹침 보정, AI의 로프 판정, Canvas가 같은 경계를 사용한다.
- 고정 틱에서 같은 이벤트와 결과가 나오는지, 로프나 상대 선수 위치가 좁아진 경계를 벗어나지 않는지, 기존 실험실 결과와 진행 중 캠페인 저장을 유지하는지 검증한다. 브라우저에서 네 경기장, 관중·투척 연출과 가로 화면을 확인한다.
