# 09. 도트 선수와 경기 변수, 장비 보상

사용자의 추가 요청에 따라 TODO의 스테이지 상대 에셋과 장비를 확장한다. 준비 화면 일러스트와 기본 실험실 규칙·결과 형식은 기존 흐름을 유지한다.

- RED COMET 스프라이트를 스타일 레퍼런스로, 기존 상대 일러스트를 캐릭터 레퍼런스로 써서 ImageGen 기본 모드로 포즈 시트를 만든다. 오른쪽을 보는 자세를 동일 크기 프레임에 정렬한다. 블루 불은 기존 도트 시트를 사용한다.
- 캠페인에서 6종 경기장 사건이 체력·분노·이동·공격 주기·넉백에 영향을 준다. 투척은 예고 범위 안에 있는 선수에게만 맞는다. 사건용 시드를 전투·AI·로프 수축 시드와 분리하고, 결과에 사건 집계를 남긴다.
- 스탯 장비 30개를 추가한다. 스테이지별 등급 가중치로 보상 3개를 뽑고 표시한 장비를 모두 기록한다. 기존 저장에서는 1차 보상까지 표시했던 기존 3종도 기록으로 이관한다. 새로고침은 시드와 표시 기록으로 같은 선택지를 복구한다.
- 회귀 검증은 기본 실험실의 결정성, 관전·헤드리스 사건 일치, 장비 선택지 중복 방지·구버전 저장 복구, 선수 시트 프레임과 운영 배포를 다룬다.

## ImageGen 프롬프트

공통 프롬프트는 “원본 RED COMET과 같은 굵은 도트, 경계가 선명한 짙은 외곽선, 오른쪽을 보는 동일 비율의 전신 선수, 투명 배경의 2×2 그리드, 좌상단 가드, 우상단 발차기, 좌하단 밀기, 우하단 공중 드롭킥”이다. 캐릭터별로 NEON VIPER의 녹색 마스크와 부츠, VELVET PHANTOM의 보라색·상아색 반가면과 망토, IRON KING의 철가면·왕관·붉은 망토와 벨트를 지정했다.
