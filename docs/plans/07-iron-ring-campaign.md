# 07. 아이언 링 캠페인

화면을 공통 프레임에 재구성하고 기존 엔진으로 네 명의 상대를 차례로 만나는 싱글 플레이 캠페인을 제공한다. TODO의 두 화면 회귀, 구현된 이동 속도 회피, 별도 메모의 스테이지·NPC·스토리·장비·파비콘·사운드·배속·라운드·체력 크기를 다룬다.

- 캠페인에서만 최대 세 라운드의 시리즈, 스테이지 보상, 스탯 예산 증가, 로컬 저장을 적용한다. 실험실은 기존 기본 상대와 단일·배치 결과를 제공한다.
- 두 장비 효과는 선택한 캠페인 참가자에게만 전달한다. 기존 공격, 카운터 및 회피 동작, 고정 timestep, 난수 스트림과 결과 버전 필드를 유지한다.
- 데스크톱과 가로 화면의 설정·관전은 동일한 16:9 영역을 사용한다. 좁은 세로 화면은 스탯 접근성과 읽기 쉬운 조작을 우선한다.
- 저장 복구, 동점 라운드, 다른 표시 배속 및 장비를 적용한 관전/headless 일치, 기본 경기 회귀, 하위 경로 에셋 로드를 확인한다.
- 무승부는 라운드 하나를 소모한다. 세 라운드까지 2승을 거두지 못하면 탈락한다. 새로고침 시 마지막 완료 라운드부터 복구하며, 진행 중이던 라운드는 동일 시드로 처음부터 다시 시작한다.
- 결승 전 승리마다 장비 하나와 훈련 3점을 받는다. 장비는 한 개 장착하며 시리즈 중 장비와 훈련 배분을 고정한다. 캐릭터 크기는 표현에만 적용한다.
