# 10. 장비에 따른 결승 난이도

사용자가 요청한 장비 운의 영향을 TODO의 장비와 스테이지에 적용한다. 조정은 결승 상대의 공격 속도·파워·체력·방어·간파와 에픽·유니크 장비 9종의 스탯 보정에 집중한다. 카본 깔창은 스탯과 로프 효과를 장비 화면에서 함께 표시한다.

균형형 훈련 배분을 고정하고 시드 1~300의 캠페인을 두 버전에서 실행했다. 시작 포인트는 공격 속도 5, 파워 3, 최대 체력 2로 배분하고 매 보상 후 파워 2와 최대 체력 1을 더했다. 결승 진출 경기 중 우승 비율을 비교했다.

| 장비 조건 | 조정 전 | 조정 후 |
| --- | ---: | ---: |
| 장비 없이 진행 | 258/292 | 1/292 |
| 약한 일반 장비 세 가지로 제한 | 272/293 | 4/293 |
| 보상에서 고른 일반·레어 장비를 결승에 장착 | 95/97 | 9/53 |
| 보상에서 고른 에픽·유니크 장비를 결승에 장착 | 198/199 | 91/243 |

보상 장비는 스탯 보정과 훈련 배분을 비교하는 휴리스틱으로 선택했다. 에픽·유니크 보정으로 선택 장비의 등급 분포도 달라져 두 등급별 표본 수는 버전별로 다르다. 비교는 해당 배분과 선택 전략의 시뮬레이션이다. 공격 위주와 체력 위주 배분에서도 후보 수치를 검토했다. 검증 범위는 44개 회귀 테스트와 운영 주소의 결승·장비 설정 확인을 포함한다.
