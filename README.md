# IRON RING · 로드 투 더 벨트

훈련과 장비로 레드 코멧을 키워 챔피언에 도전하는 브라우저 레슬링 오토배틀러다. 캠페인 관전과 전투 실험실의 렌더링 없는 시뮬레이션이 전투 엔진, FSM AI, 시드 RNG를 공유한다.

## 실행

외부 라이브러리나 빌드 과정은 필요 없다. ES 모듈을 사용하므로 저장소 루트에서 정적 서버를 실행한다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 연다. 모든 경로는 상대 경로이므로 GitHub Pages 하위 경로에서도 동작하도록 구성했다.

## 캠페인

1. 훈련 포인트 10점을 배분하고 BLUE BULL, NEON VIPER, VELVET PHANTOM, IRON KING 순으로 도전한다.
2. 각 상대와 최대 세 라운드를 치르며 두 라운드를 먼저 이기면 다음 스테이지로 진출한다. 무승부도 한 라운드를 소모한다. 세 라운드 안에 2승을 거두지 못하면 이번 토너먼트가 끝난다.
3. 결승 전 세 스테이지에서 이길 때마다 훈련 포인트 3점과 장비 하나를 얻는다. 새 장비는 즉시 장착되며 시리즈 시작 전에 교체하거나 해제할 수 있다.
4. 브라우저가 스탯·장비 변경, 라운드 결과와 보상을 자동 저장한다. 진행 중에 새로고침하면 마지막으로 완료한 라운드 다음부터 시작한다.

### 경기장 이벤트

지하 체육관, 네온 아레나, 벨벳 극장, 철의 왕좌는 각기 다른 링과 관중석을 사용한다. 크리티컬이나 로프 드롭킥 등 강한 공격이 적중하면 환호가 터진다. 관중석에서 가끔 의자나 쓰레기가 링 옆으로 날아오며, 투척 소품은 선수에게 닿아도 전투에 영향을 주지 않는다.

시리즈가 3라운드에 들어가면 약 3~4.5초 뒤 양쪽 로프가 약 4초 동안 안쪽으로 이동한다. 좁아진 공간은 선수 이동, 넉백과 로프 드롭킥 판정에 적용된다. 같은 시드에서는 수축 시점과 폭, 관중 이벤트가 재현된다.

| 장비 | 효과 |
| --- | --- |
| 카본 깔창 | 로프 드롭킥 전진 거리 35% 증가 |
| 하이힐 | 일반 발차기 치명타 확률 12%p 증가 |
| 챔피언 랩 | 장착 중 방어와 간파 각각 2 증가 |

### 조작

- **훈련**에서 `+`와 `−`로 포인트를 옮기고 `배분 초기화`로 해당 스테이지까지 얻은 포인트를 돌려받는다. 시리즈 동안은 배분과 장비가 고정된다.
- **관전**에서는 `일시정지`, `재개`, `1×/2×`를 쓸 수 있다. `라운드 재시작`이나 `R`을 누르면 같은 시드로 다시 진행한다. `결과 보기`는 현재 라운드의 남은 틱을 즉시 계산한다.
- **사운드**는 상단 버튼에서 켜고 끈다. 브라우저 오디오 정책에 따라 소리는 최초 사용자 입력 이후에 재생된다.

## 전투 실험실

상단의 `실험실`을 열면 입력 시드와 현재 훈련 스탯으로 BLUE BULL과 단일 관전 또는 헤드리스 1회, 100회, 1,000회 시뮬레이션을 실행할 수 있다. 실험실에는 캠페인 장비 보정을 적용하지 않으며 캠페인 기록을 변경하지 않는다. `취소`는 이미 계산한 경기까지 집계한다. `JSON 다운로드`는 마지막 실행 결과를 저장한다.

## 에셋

```text
asset/
├─ gameboard/
│  └─ arena_480x270.png
├─ campaign/
│  ├─ arena-banner.jpg
│  └─ 상대 일러스트 PNG 4개
├─ favicon.ico
├─ player_sprite/
│  ├─ red_comet_sheet.png
│  └─ blue_bull_sheet.png
├─ sound/
│  ├─ ring-swing.wav
│  ├─ ring-impact.wav
│  ├─ ring-bell.wav
│  └─ ring-crowd.wav
└─ play_sample/
   ├─ sample_play.png
   └─ sample_setting.png
```

- Canvas는 1920×1080 논리 해상도를 사용한다. 데스크톱과 가로 모바일에서는 설정과 관전이 공통 16:9 프레임을 차지한다. 캠페인 경기장은 Canvas로 그리며 실험실은 기존 경기장 PNG를 사용한다.
- 레드 코멧과 블루 불의 관전용 시트는 543×724 프레임 4개를 가로로 배치한 RGBA PNG다. 나머지 상대는 준비 화면의 투명 일러스트를 관전용 포즈에도 사용한다.
- 최대 체력이 높을수록 화면 속 선수 크기가 커진다. 충돌과 공격 거리는 기존 엔진 수치를 사용한다.
- `sample_play.png`와 `sample_setting.png`는 UI 분위기 참고 자료이며 런타임 화면에 직접 사용하지 않는다.

## 스테이터스

원본 스탯의 기준값은 모두 10이다. 최대 체력은 `50 + maxHealth × 5`, 공격 주기 배율은 `clamp(1 - 0.035 × (attackSpeed - 10), 0.65, 1.35)`, 이동 배율은 `clamp(1 + 0.04 × (moveSpeed - 10), 0.60, 1.60)`으로 계산한다.

피해는 `floor(baseDamage + power × 0.60 - defense × 0.35)`이며 최소 1이다. 치명타 확률은 12%, 배율은 `clamp(1.25 + sharpness × 0.025, 1.25, 2.00)`, 카운터 확률은 `clamp(0.05 + insight × 0.01, 0.05, 0.45)`이다. 이동 속도 회피율은 `clamp((moveSpeed - 10) × 0.5%p, 0%, 5%)`이며 기준값 10까지는 발동하지 않는다. luck는 현재 결과에 보존되지만 전투 규칙과 예산 배분에는 사용하지 않는다.

## 결정성과 버전

- 고정 timestep: 1/60초
- 제한 시간: 3,600 tick
- RNG: Mulberry32 기반 seed RNG
- 매치별 seed: `mix32-v1` 파생 정책
- 전투 규칙: 기본 `0.6.0`, 장비 동작 보정 `0.7.0`, 캠페인 경기장 규칙 `0.8.0`
- AI 프로필: `0.2.0`
- 스탯 규칙: `1.1.0`

전투, AI, 치명타 판정에서는 `Math.random()`을 사용하지 않는다. 같은 seed와 설정의 관전/headless 결과는 `mode` 필드를 제외하고 동일하다.

카운터는 일반 공격을 무효화한 뒤 18 tick(0.3초) 후 밀기 반격을 적용한다. 같은 tick에 카운터와 일반 공격이 함께 성립하면 카운터가 우선하며, 카운터에 성공한 선수의 일반 공격도 취소된다. 로프 드롭킥은 카운터 대상이 아니며, 사용 시 선수 머리 위에 안내 문구가 표시된다.

카운터가 실패하거나 불가능한 공격에는 회피를 판정한다. 회피 성공 시 일반 공격과 로프 드롭킥의 피해·경직·넉백·분노를 모두 무효화하고 `회피!`를 표시한다. 카운터 성공 시에는 회피 RNG를 소비하지 않으며, 회피한 선수의 같은 tick 공격은 취소하지 않는다.

실험실에서 단일 관전을 시작한 뒤 `결과만 1회`를 누르면 그 경기의 시드와 스탯을 다시 사용한다. 관전이 끝나면 `mode` 필드를 제외한 전투 결과를 자동 비교하고, 차이가 있으면 첫 번째로 다른 필드를 표시한다.

## 결과 데이터

단일 결과에는 seed, 실행 모드, 버전, 승자, 결과 유형, 경과 tick/초, 양측 `rawStats`와 `derivedStats`, 최종 체력·분노, 피해량, 행동별 공격/명중/치명타, 로프 드롭킥, 카운터 및 회피 지표가 포함된다.

캠페인 경기 결과의 `arena`에는 스테이지 ID, 종료 시 링 경계, 관중 이벤트 횟수와 3라운드 수축 설정이 기록된다.

배치 결과에는 실행 metadata, 양측 스탯 snapshot, 집계 지표와 compact match summary가 포함된다. tick별 이벤트는 대량 결과에 저장하지 않는다.

## 테스트

Node.js가 있으면:

```bash
npm test
```

macOS 시스템 JavaScriptCore로도 외부 의존성 없이 실행할 수 있다.

```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc \
  -m tests/run-tests.js
```

테스트는 RNG와 시드 파생, 스탯과 피해 공식, 카운터·회피 우선순위, 링 경계, 집계, 100개 시드의 기본 관전·헤드리스 결과 일치, 캠페인 라운드·보상·저장 복구와 장비별 효과를 확인한다.
